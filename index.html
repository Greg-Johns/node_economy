p5 Autonomous Node Economy

A single-page p5.js autonomous agent simulator. A population of nodes moves across the canvas, each driven by one or more motivations (movement logic) and drawn by one or more visualizations (rendering logic). Optional restrictions are applied per frame to every node by NodeGroup.render(). The simulation stops when all nodes come to rest (speed ≤ 0.01).

→ Component Reference (motivations, restrictions, visualizations)

Use the Simulation Controls panel in the top-right to toggle motivations, visualizations, and restrictions, and tune their parameters. Changes auto-restart the simulation.

Key Mappings

Key Action
r Restart the animation (re-runs setup()).
Space Pause / resume the animation loop.
s Save the current canvas as a PNG (nodes_<timestamp>_<frame>.png).
i Save the current canvas parameter information as a JSON (nodes_<timestamp>_<frame>.json).
c Clear the canvas (redraw background) while keeping nodes in their current state.

Project Structure

  • src/sketch.ts — Entry point. Bootstraps AutonomousNodeEconomy + NodeGroup, creates 1000 nodes (INITIAL_NODE_COUNT, must stay even for MagnetPairMotivation pairing), drives the p.draw() loop, and handles key input.
  • src/engine/AutonomousNodeEconomy.ts — Wraps a NodeGroup and a ColorPallet; sketch-level orchestration.
  • src/engine/NodeGroup.ts — Collection of nodes. render() runs the per-frame motivate → restrict → move → render pipeline. removeUnhealthyNodes() deletes nodes with negative health.
  • src/engine/Node.ts — Single node: position (x, y), velocity (dx, dy), health, motivations, visualizations.
  • src/engine/Motivation.ts, Visualization.ts, Restriction.ts — Abstract base classes you extend to build new behaviors.
  • src/engine/ColorPallet.ts + customcolorpallets/ManualColorPallet.ts — Palette of colors; index 0 is always the background color.

Interface Docs

Node

  • new Node(x, y, health = 100) — create a node at x, y with starting health.
  • x, y — current position.
  • dx, dy — current velocity vector (set by motivations each frame).
  • health — positive = alive; negative = marked for removal.
  • getSpeed(), getDirection(), getDistance(other) — motion/distance helpers.
  • addMotivation(motivation), addVisualization(visualization).
  • killHealth(), changeHealth(delta), getHealth().

NodeGroup

  • addNode(node), getNodeCount(), getNode(i), getNodeIndex(node).
  • getNextNode(node), getPreviousNode(node) — circular neighbors.
  • addNodeRestriction(restriction) — applies to every node each frame.
  • initialize() — calls initialize on every node's motivations and visualizations.
  • render() — per node: motivate → restrictions → move → render.
  • removeUnhealthyNodes() — deletes nodes with health < 0.
  • isGroupMoving() — true if any node speed > 0.01.

Base Classes (extend these)

  • Motivation: motivate(n) sets dx/dy influence; optional initialize(n).
  • Visualization: render(n) draws the node; optional initialize(n).
  • Restriction: restrict(n) mutates position/direction/health after movement.
  • ColorPallet: getColor(index, alpha) → [r,g,b,a]; index 0 = background.

Built-in Motivations (src/engine/custommotivations/)

Class Constructor Behavior
MagnetMotivation scaleX, scaleY, dampeningX, dampeningY Spring-like pull toward a magnet node.
MagnetPairMotivation same as MagnetMotivation Pairs even↔odd nodes as magnets.
MagnetRandomMotivation same as MagnetMotivation Links to a random other node.
MagnetChainMotivation same as MagnetMotivation Links node → next node (chain).
SocialPersonalMotivation personalRadius, strength Avoids neighbors within personal radius (clustering/separation).
SocialVisibleMotivation visibleRadius, strength Attracts toward neighbors within visible radius.
FollowFarthestMotivation (none) Steers toward the farthest node in the group.
CircularMotivation radius, angle Tangential/circular motion; angle advances 0.1/frame.
RandomXMotivation / RandomYMotivation amount Random impulse per frame on one axis.
TowardsXMotivation / TowardsYMotivation target, strength Pulls toward a fixed axis position.
SineXMotivation / SineYMotivation amplitude, phase, damping Oscillatory force; phase advances 0.1/frame.
AgingHealthMotivation dHealth Subtracts health each frame (nodes eventually die).

Built-in Visualizations (src/engine/customvisualizations/)

  • SpeedCircleDrawVisualization — curved trails scaled by speed (continuous drawing).
  • SpeedCircleVisualization — circle radius = scalingFactor × speed; optional fill.
  • SpeedSquareVisualization — square sized by speed, rotated by direction.
  • NeighborVisualization — lines to neighbors within a radius, alpha fades with distance.
  • PixelVisualization — single pixel per node.
  • NodeMotivationVisualization — filled body circle + direction-vector line.

Built-in Restrictions (src/engine/customrestrictions/)

  • BoundingBoxRandomJumpRestriction — teleport out-of-bounds nodes to a random in-bounds point.
  • BoundingBoxKillRestriction — kill (negative health) out-of-bounds nodes.
  • BoundingBoxWrapRestriction — toroidal wrap (exit one edge, re-enter opposite).
  • MinSpeedRestriction — enforce a minimum speed floor.
  • MaxSpeedRestriction — clamp speed to a maximum.

Color Pallet (customcolorpallets/ManualColorPallet.ts)

  • addColor(r, g, b) — add a color; index 0 MUST be the background color.
  • getColor(index, alpha) / getColor(index1, index2, offset, alpha) / getColor(nx, ny, alpha).
  • getColorCount() — number of colors excluding background.

Experimenting — Things to Try

  • Change the node count: edit INITIAL_NODE_COUNT in src/sketch.ts (must stay even for MagnetPairMotivation).
  • Add/remove motivations: in setup(), call newNode.addMotivation(new ...Motivation(...)) or swap out MagnetPairMotivation.
  • Add restrictions: call nodeGroup.addNodeRestriction(new BoundingBoxWrapRestriction(0, 0, p.width, p.height)) to keep nodes inside the canvas.
  • Swap visualizations: replace SpeedCircleDrawVisualization with SpeedCircleVisualization, PixelVisualization, NeighborVisualization, etc.
  • Tweak the palette: add more colors via colorPallet.addColor(r, g, b) and reference them by index in visualizations.
  • Enable aging: add newNode.addMotivation(new AgingHealthMotivation(-1)) so nodes die off and get removed.
  • Restart: press r to reset; press c to clear the canvas while keeping node state.
