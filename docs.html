How it works

Each Node holds a position (x, y), velocity (dx, dy), health, a list of motivations, and a list of visualizations. Every frame, NodeGroup.render() runs this pipeline per node:

  1. Motivate — each motivation computes its own dx/dy influence; the node sums them into its total velocity.
  2. Restrict — each registered restriction mutates position/direction/health after movement.
  3. Move — x += dx, y += dy.
  4. Render — each visualization draws the node.

The simulation loop stops when all nodes come to rest (speed ≤ 0.01). Press r to restart. Node count (INITIAL_NODE_COUNT) must stay even because MagnetPairMotivation pairs even↔odd indices.

Motivations

Motivations extend the abstract Motivation base class. Each implements motivate(n), which sets its own dx/dy influence. The node aggregates all motivations' dx and dy into its total velocity each frame. Optional initialize(n) runs once at setup.

Class Constructor parameters Behavior
MagnetMotivation scaleX = 600, scaleY = 700, dampeningX = 0.964, dampeningY = 0.964 Spring-like pull toward a configured magnet node.
MagnetPairMotivation scaleX = 100, scaleY = 100, dampeningX = 0.64, dampeningY = 0.64 Same math as MagnetMotivation; pairs node i with i+1 (even) or i-1 (odd) as its magnet. Requires an even node count.
MagnetRandomMotivation scaleX = 50, scaleY = 50, dampeningX = 0.964, dampeningY = 0.964 Same math as MagnetMotivation; links to a random other node (dynamic linking).
MagnetChainMotivation scaleX = 5, scaleY = 5, dampeningX = 0.964, dampeningY = 0.964 Same math as MagnetMotivation; links node i → node (i+1) mod N (chain structure).
SocialPersonalMotivation personalRadius, strength Avoids neighbors within personalRadius (separation/clustering). Sums normalized away-vectors and scales by strength.
SocialVisibleMotivation visibleRadius, strength Attracts toward neighbors within visibleRadius (cohesion). Sums normalized toward-vectors and scales by strength.
FollowFarthestMotivation (none) Steers toward the farthest node in the group (unit direction vector).
CircularMotivation radius, angle Tangential/circular motion. Angle advances by 0.1 rad/frame.
RandomXMotivation / RandomYMotivation amount Random impulse per frame on one axis: (random×2 − 1) × amount.
TowardsXMotivation / TowardsYMotivation target, strength Pulls toward a fixed axis position: dx += (target − pos) × strength.
SineXMotivation / SineYMotivation amplitude, phase, damping Oscillatory force: sin(phase) × amplitude × damping; phase advances by 0.1 rad/frame.
AgingHealthMotivation dHealth Subtracts dHealth from node health each frame (nodes eventually die and are removed). Pass a negative value to age.

Restrictions

Restrictions extend the abstract Restriction base class. Each implements restrict(n), which mutates a node's position/direction/health after movement. Register with nodeGroup.addNodeRestriction(...) so it applies to every node each frame.

Class Constructor parameters Behavior
BoundingBoxRandomJumpRestriction x1, y1, x2, y2 If out of bounds, teleports to a random in-bounds point: x = x1 + random × (x2 − x1).
BoundingBoxKillRestriction x1, y1, x2, y2 If out of bounds, sets health to −1 (killed; removed next frame).
BoundingBoxWrapRestriction x1, y1, x2, y2 Toroidal wrap — exit one edge, re-enter opposite edge.
MinSpeedRestriction minSpeed Enforces a speed floor: dx = minSpeed × cos(dir), dy = minSpeed × sin(dir) when 0 < speed < minSpeed.
MaxSpeedRestriction maxSpeed Clamps speed to a max: dx = maxSpeed × cos(dir), dy = maxSpeed × sin(dir) when speed > maxSpeed.

Visualizations

Visualizations extend the abstract Visualization base class. Each implements render(n), which draws the node using the p5 instance and a ColorPallet. Palette index 0 is always the background color.

Class Constructor parameters Behavior
SpeedCircleDrawVisualization p, colorPallet, scalingFactor, angle, dAngle, strokeColorIndex, strokeColorAlpha, strokeColorWidth, fillColorIndex, fillColorAlpha, fillColorWidth Continuous curved trails scaled by speed. Radius = scalingFactor × speed; draws a line from last point to new point each frame (angle advances by dAngle).
SpeedCircleVisualization p, colorPallet, scalingFactor, strokeColorIndex, strokeColorAlpha, fillColorIndex = 0, fillColorAlpha = 0 Circle radius = scalingFactor × speed; optional fill when fillAlpha > 0.
SpeedSquareVisualization p, colorPallet, scalingFactor, strokeColorIndex, strokeColorAlpha, fillColorIndex = 0, fillColorAlpha = 0 Square sized by speed (radius = scalingFactor × speed), rotated by getDirection(); visualizes both speed (size) and direction (orientation).
NeighborVisualization p, colorPallet, neighborRadius, maxAlpha, toggleEnabled Lines to neighbors within neighborRadius. Alpha fades linearly with distance: maxAlpha − maxAlpha × dist / neighborRadius; palette index shifts with distance.
PixelVisualization p, colorPallet, index, alpha Single pixel at node position with fixed palette index and alpha.
NodeMotivationVisualization p, colorPallet, bodyRadius, dirScale, bodyColorIndex, bodyColorAlpha, lineColorIndex, lineColorAlpha Filled body circle + direction-vector line: end = pos + dirScale × speed × (cos(dir), sin(dir)).

Math-based parameter details

Core node helpers (from src/engine/Node.ts):

  • getSpeed() = sqrt(dx² + dy²) — velocity magnitude.
  • getDirection() = atan2(dy, dx) — travel angle in radians.
  • getDistance(other) = sqrt((x−other.x)² + (y−other.y)²) — Euclidean distance.

Motivation math

Motivation Per-frame formula
Magnet* dx += (magnet.x − n.x) / scaleX; dx *= dampeningX;
dy += (magnet.y − n.y) / scaleY; dy *= dampeningY.
scale controls spring stiffness (larger = weaker pull); dampening ∈ (0,1) damps velocity each frame.
SocialPersonalMotivation For each neighbor with 0 < d < personalRadius: sum ((n.x − other.x)/d, (n.y − other.y)/d);
then dx = (sum/count) × strength, dy = (sum/count) × strength. (Repulsion / separation.)
SocialVisibleMotivation Same as above but vector points toward the neighbor: ((other.x − n.x)/d, ...); applies when 0 < d < visibleRadius. (Attraction / cohesion.)
FollowFarthestMotivation dx = (farthest.x − n.x) / maxD, dy = (farthest.y − n.y) / maxD — unit vector toward the farthest node.
CircularMotivation dx = −sin(angle) × radius, dy = cos(angle) × radius; angle += 0.1 rad/frame.
RandomX/YMotivation dx = (random × 2 − 1) × amount (or dy) — uniform impulse in [−amount, +amount].
TowardsX/YMotivation dx += (target − n.x) × strength (or dy) — linear pull proportional to distance.
SineX/YMotivation dx = sin(phase) × amplitude × damping (or dy); phase += 0.1 rad/frame.
AgingHealthMotivation health += dHealth each frame. Pass negative dHealth to make nodes die.

Restriction math

Restriction Per-frame formula
BoundingBoxRandomJumpRestriction If out of bounds: x = x1 + random × (x2 − x1), y = y1 + random × (y2 − y1).
BoundingBoxKillRestriction If out of bounds: health = −1 (removed next frame).
BoundingBoxWrapRestriction Toroidal: exit left → re-enter right (and vice versa); exit top → re-enter bottom.
MinSpeedRestriction If 0 < speed < minSpeed: dx = minSpeed × cos(dir), dy = minSpeed × sin(dir).
MaxSpeedRestriction If speed > maxSpeed: dx = maxSpeed × cos(dir), dy = maxSpeed × sin(dir).

Visualization math

Visualization Per-frame formula
SpeedCircle* radius = scalingFactor × speed.
SpeedCircleDrawVisualization radius = scalingFactor × speed; angle = (angle + dAngle) mod 2π;
point = (x + radius×cos(angle), y + radius×sin(angle)); draws line from previous point.
SpeedSquareVisualization radius = scalingFactor × speed; translate to (x + radius/2, y + radius/2), rotate by dir = atan2(dy, dx), draw radius × radius square.
NeighborVisualization Line drawn if dist < neighborRadius;
paletteIndex = floor(colorCount × dist / neighborRadius);
alpha = maxAlpha − maxAlpha × dist / neighborRadius.
NodeMotivationVisualization Body circle radius = bodyRadius;
line end = (x + dirScale × speed × cos(dir), y + dirScale × speed × sin(dir)).
